# 四个累计版本的正确性证据

本表对应r32-v2消融定义，数据读取自[汇总JSON](../../artifacts/submission/final_r32_matrix/matrix.json)。全行32槽；历史单槽初始适配不进入当前四行比较。

## 实验协议与判定

开发200条由HumanEval164条与A前36条构成，每条HF参考64token。自然greedy生成，不强制注入HF历史；匹配按同一提示的同一token位置统计，分母固定12800，缺失位置不删除。完整序列一致数附加报告。四条长输入各64输出，16k单列。

HumanEval使用官方固定套件，关闭thinking、最多2048token，每题一次生成；pass@1=通过题数/164，比较与HF的绝对百分点差。提取失败和预算触顶仍在分母中；二者可重叠，不相加解释为独立失败数。HF为145/164。MTP关闭、模型单卡，相关额外一致性检查不适用。
