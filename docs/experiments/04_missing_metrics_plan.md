# 两条路线的缺失指标补测计划

## 必补项：精度优先最终组合C200

使用`r_swa_decode4`，即已通过完整正确性验证及A512/B50测量的①②③，不启用prefix、chunk、Graph或原生专家。单卡32槽，模型长度16640；固定原C200输入、速率0.3请求/秒、256输出、greedy、stream、ignore_eos，保留题给180秒请求超时。

一次测量需要约15–25分钟，服务初始化和清理另计；每轮进程预算30分钟，超预算记录失败。默认一轮，建议直接执行三轮：每轮新建服务、KV和客户端，各自保留请求级数据库。共约45–75分钟；每轮种子42与输入不变。程序预算不是客户端180秒超时，两者分别记录。

采集C TPOT p99、TTFT p99、完成数、失败数、输出长度和输入身份校验、请求起始时间跨度、实际batch、服务启动配置及加载审计。失败结果同样归档，不改速率、不延长请求超时、不删除失败请求。分位数仍按客户端成功请求计算，并与完整分母200同时展示；不足200成功时不视为完整负载通过，也不与全部成功版本计算延迟加速比。

完整验收来源为`20261117T170629593110Z_accuracy/r_swa_decode4`，启动前校验源码、原验收和输入身份。该轮不重生成HumanEval。已有①②C结果与性能优先四行结果不重复测量。

命令：

```bash
/opt/venv/bin/python /workspace/tencent-mellum-precision-third/scripts/run_precision_c_completion.py --gpu 0 --repeats 3
```

如果只需先补单次矩阵，将`--repeats 3`替换为`--repeats 1`。不要同时在同一卡启动其他实验。

## 三次中位数的边界

此次三轮C可形成最终精度优先组合的本地C重复数据；只有三轮均200/200完成时才输出有效完整负载三轮中位数。否则逐轮呈现结果，保留成功条件下的分位数，不从少数成功轮筛选中位数。

两条路线既有A/B和性能优先C并非三次统一重测，目前矩阵应继续标明单次实测或显式历史复用。题目所述空闲机器隐藏集三次中位数属于裁判最终测量，候选人本地实验无法替代。若另需所有行的本地三次重复，应另开完整重复实验，不将本次C补测称为全矩阵三次验证。按当前成本，优先补齐唯一空缺的C行，避免将所有完整矩阵重跑作为交付前置条件。

## 不适用项

两条路线均不启用MTP或双卡并行，对应条件性正确性检查继续标为不适用，不引入新功能来补表。当前正确性矩阵已有全部累计行的token、长输入及HumanEval结果，不重复测试。
