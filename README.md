# Mellum 2.1 on ATOM

Mellum2.1-12B-A2.5B-Thinking adaptation and optimization in the frozen AMD ROCm ATOM environment.

This repository contains ATOM upstream history under `ATOM/`, project scripts, documentation, and lightweight experiment evidence. Large model weights, virtual environments, and raw tensor outputs are external assets.

The initial import preserves ATOM's history without squash. Project-specific changes are committed separately; historical experiments are documented rather than reconstructed as invented commits.
